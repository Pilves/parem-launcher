# M6-WP58 string fallbacks

These user-visible strings deliberately fall back to base English in all existing
non-English launcher locales: `ar`, `de`, `es-rES`, `es-rUS`, `et`, `fr`, `he`,
`hr`, `hu`, `in`, `it`, `ja`, `pl`, `pt-rBR`, `ru-rRU`, `sv`, `tr`, `uk`, and
`zh`:

- `widget_setup_in_progress`, `widget_unavailable`
- `grayscale_restore_pending`, `grayscale_restore_access`, `grayscale_android_settings`, `grayscale_settings_unavailable`
- `limit_usage_access_missing`, `limit_usage_unavailable`, `limit_settings_unavailable`

Release follow-up: translate these nine keys for those locales and arrange native
review before claiming localized coverage. No translation has been guessed here.
