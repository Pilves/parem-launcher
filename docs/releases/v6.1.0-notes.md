# Parem Launcher v6.1.0

Requires Android 10 or newer.

Parem is written by AI coding agents under Patrick's direction.

- Find widgets by app, search and size. On Android 15 and later, widgets that publish a generated preview can show it in the picker.
- Search and review app selections before saving, and manage hidden apps from their own menu.
- Find settings in clearer groups and use quick actions for Focus and grayscale.
- Choose Estonian as the launcher language. New installs start with Large text.
- Keep unavailable widgets as removable placeholders, cancel widget configuration safely, and import settings with clearer validation.
- Apply Focus, app limits and mindful pause to more routes from the home screen.

## Updating

Install over your existing Parem installation without uninstalling it or clearing its data. Exporting settings first gives you a backup.
