# Parem Launcher v6.0.0

Parem is a minimal Android launcher: a home screen of plain app names, one
search field, and optional tools for using your phone less. Requires Android 10
or newer.

Parem is written by AI coding agents under Patrick's direction.

## Since v6.0.0-beta.2

- A new green icon.
- Home shows one add-app hint for empty slots, leaves filled slots in place and
  keeps widgets clear of the clock without counting the top inset twice.
- The drawer search bar aligns with the app list in portrait.
- Android screensaver activity no longer counts as screen time or toward limits.
- Quieter transitions and press feedback across onboarding, settings and sheets.
- Daily wallpaper reads its list from Parem's own site instead of the upstream
  author's gist.
- Weather sends coordinates rounded to the nearest 0.05 degrees, and says so.
- Android cloud backup no longer copies Parem's settings, usage counts or
  weather place. Use Export settings to move them.
- The mindful pause now counts from when its sheet begins drawing.
- First-use and default-home prompts stay clear of landscape widgets.
- Permission disclosures are translated for the shipped languages. These are
  machine-made drafts and still need review by native speakers.

This APK is the full build, which can pair over wireless debugging on the phone
to grant grayscale. The Google Play build grants grayscale from a computer only.

The full list is in `CHANGELOG.md`.

## Updating

Install over your existing Parem installation without uninstalling it or
clearing its data. Exporting settings first gives you a backup. Older
Olauncher-branded builds used a different package and are not an in-place
Parem update.
