# Parem Launcher v6.0.0-rc.2

A release candidate for 6.0.0, prepared to test the combined fixes before the
final version. Requires Android 10 or newer.

Parem was built with AI. Patrick has not written its code by hand. There has
been no human code review or independent security audit for this release, so
this one may have rough edges.

What changed is in `docs/releases/v6.0.0-notes.md` and `CHANGELOG.md`.

Install over your existing Parem installation without uninstalling it or
clearing its data. Exporting settings first gives you a backup.
