# Parem Launcher v6.0.0-rc.1

A release candidate for 6.0.0, published to prove the signed build and the
release process before the final version. Requires Android 10 or newer.

Parem is written by AI coding agents under Patrick's direction.

What changed is in `docs/releases/v6.0.0-notes.md` and `CHANGELOG.md`.

Install over your existing Parem installation without uninstalling it or
clearing its data. Exporting settings first gives you a backup.
