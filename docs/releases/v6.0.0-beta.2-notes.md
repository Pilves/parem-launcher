# Parem Launcher v6.0.0-beta.2

This beta adds warmer light/dark colours, clearer tablet typography and
independent wallpaper dimming. It includes the Calm tools, search improvements
and accessibility work introduced in beta.1. Requires Android 10 or newer.

- Focus app-search results stay above the keyboard. Landscape Settings includes
  App limits, Focus, Grayscale and quiet notifications.
- Tablet sheets use readable widths; folder, website, widget, Focus and limit
  sheets share consistent scrolling and sizing.
- Widget sizing and home-capacity warnings are improved. Drawer suggestions no
  longer overlap search. Hidden-app hints respect locked Private Space.
- Idle polling is reduced. Failed app lookups keep existing home names.
- The unfinished per-slot swipe-up binding has been removed; swipe up opens
  All apps.

## Updating

Install over your existing Parem installation without uninstalling it or
clearing its data. In-place QA upgrades from v5.5.1 and v5.7.0 retained saved
settings; the v5.7.0 check also retained four existing widgets. Exporting settings
before updating provides an additional backup. Older Olauncher-branded builds
used a different package and are not an in-place Parem update.

## Known limitation

With Focus off and no default browser, web links use Android's chooser; the
browser selected there bypasses browser-specific limits and mindful pause.
With Focus on, Parem chooses an allowed browser or blocks the open.

Tablet typing still misses our strict jank-percentage target (worst measured
frame 18 ms). Extended battery validation is deferred to ordinary-use beta testing.

This remains a beta, not the final 6.0 release.
