Fresh empty stores use Large on first activity configuration; existing nonempty stores without a scale use Medium.
Contract: explicit restored values win; imports missing the scale preserve the device choice. Device transfer restores the source preferences, not the destination choice.
Not verified: OEM device transfer, physical large-text layout or spoken accessibility; the CI LocalTransport check covers one legacy-source scenario.
Easy to get wrong: an entirely empty old install, a store emptied by device-only cleanup, or platform-erased data looks fresh and receives Large; no restore engine preserves erased settings.
Easy to get wrong: nothing may write main preferences before MainActivity.attachBaseContext on first launch.
