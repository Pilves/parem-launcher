Settings import bounds file size and JSON nesting and rejects out-of-range registered settings before applying any changes.
Contract: import accepts at most 2 MiB UTF-8 with standard JSON, including escaped folder JSON; rejected files leave preferences and history unchanged.
Not verified: external document providers and oversized legacy exports on physical devices; previously exported files over 2 MiB or using nonstandard JSON are rejected.
Easy to get wrong: folder data is JSON inside a string; the legacy LAUNCHER_RECREATE_TIMESTAMP is exported despite a stale Prefs comment, so preserve its type and validate nonnegative.
