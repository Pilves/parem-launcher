Drawer search normalises the query once per keystroke (`SearchMatcher.Query`), keys settings rows, hidden labels and contact sort names once per load, and reuses label and shortcut keys across list emissions and drawer opens.
Contract: every String-taking matcher keeps its old result; the Query overloads are pinned to a verbatim copy of the old matcher by `SearchMatcherParityTest`, and `ContactMatcher.best` equals `match().first()` including ties.
Private Space: a query that cannot show the entry returns before any binder call; the profile handle is cached on `PackageChangeTracker.stamp()` and dropped in `onStart` (profile add/remove and default-home changes bump no stamp); lock state is never cached.
The history rows still use a full rebind: range notifications were tried and reverted because they change scroll position and expose stale usage text; that is an open PO decision.
Not verified: typing jank on hardware, and the Private Space steps on API 36.
