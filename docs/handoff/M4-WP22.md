Rotating with Settings open no longer crashes: `AppearanceSettingsCard` applies the status-bar state from `doOnAttach` instead of touching `window.insetsController` while the fragment is restored before the decor exists.
Contract: anything in a settings card that needs the window must wait for attach.
Not verified: rotation in every settings state on a device, and that Android keeps Parem as default home afterwards (the crash used to drop it).
Easy to get wrong: the NPE only appears on fragment restore during activity inflation, never when opening Settings normally — a regression looks like a rotation-only crash.
