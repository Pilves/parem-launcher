The empty-home long-press menu opens expanded in landscape: `HomeGesturesController.showHomeLongPressMenu` builds it with `BottomSheetMenu`, whose `show()` sets `STATE_EXPANDED` and `skipCollapsed`, so the landscape peek state that hid Settings no longer applies.
Contract: the code change itself landed with M4-WP53's menu rebuild (`fbdee36`); this package verified that no other long-press path bypasses `BottomSheetMenu.show()` and closes the row with its changelog line, no further code.
Not verified: no device run — the expanded open in landscape on a phone and on the Tab S8 is a device-pass item, as is that the sheet still scrolls to Settings at 200% font in landscape.
Easy to get wrong: any sheet built outside `BottomSheetMenu` (a direct `BottomSheetDialog`) gets Material's landscape peek again; keep new home menus on the builder.
