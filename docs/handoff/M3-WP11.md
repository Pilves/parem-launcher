Settings has "Crash reports" (`Prefs.crashReportsEnabled`, key `CRASH_REPORTS_ENABLED`, default false); `ParemApp` installs `helper/CrashReporter`, which writes `CrashReportFormatter.format(...)` (64 KB cap) to `noBackupFilesDir/crash.txt` and chains to the previous handler; on the next start `ui/CrashReportSheet` offers the text to share or discard.
Contract: no dependency, no network, no destination address (decision: share sheet only); the handler body is wrapped in a catch-all so the crash always reaches the system handler and Play vitals.
Not verified: HOME relaunch and chaining behaviour on OEM Android 15–16; the sheet after a startup crash loop (the file waits for the next good start).
Easy to get wrong: install stays in `Application`, not `MainActivity`, or service and worker crashes are missed; the report can hold user text from exception messages, which is why the user sees it before sending.
