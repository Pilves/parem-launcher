Android instrumentation uses a listener to finish app tasks and wait for standard task teardown before orchestrator clears package data.
Contract: clearPackageData remains enabled; the listener skips test discovery and logs unavailable dumps or a bounded wait timeout.
Contract: HOME-sensitive tests inject HOME once and verify Parem's resumed activity and visible home, with diagnostics on failure.
Not verified: full CI precursor counts and task settling on every emulator profile until the PR checks complete.
Easy to get wrong: test-package EmptyActivity runs in a different UID; matching its task in a dump does not itself finish it.
