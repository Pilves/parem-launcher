`Perf APK pair` (`.github/workflows/perf-apks.yml`) builds two refs as minified Play release APKs in one run with one throwaway key and uploads `perf-apks`: base as `com.parem.launcher.perf`, head as `com.parem.launcher.perfb`, both mappings and a MANIFEST with each commit.
Contract: the suffix comes from `scripts/perf-apk.init.gradle` via `-PperfSuffix`, loaded from the workflow's own checkout, so any older base ref builds without changes; the job fails unless both package names come out as expected.
It runs on dispatch, and on a pull request only when the workflow or the init script changes (self-test).
Not verified: installing both side by side on a device. Each run makes a new key, so a reinstall from a later run needs an uninstall first.
Easy to get wrong: both installs are labelled "Parem"; pick the default home by package with `cmd role add-role-holder android.app.role.HOME <pkg>`.
