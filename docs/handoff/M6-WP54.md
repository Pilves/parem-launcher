New home and folder names reject known invisible-only input; blank website labels use the visible host fallback.
Contract: visible text keeps its Unicode characters and pre-existing stored labels are never rewritten.
Not verified: font-specific visibility of every Unicode character and real-device accessibility.
Easy to get wrong: format characters can be essential inside visible RTL or emoji sequences; do not strip them.
