Settings › Home Screen has "Search history" (off by default); when on, the empty drawer lists the last five drawer launches and searches (`RecentHistoryAdapter`), a tap repeats one, Clear wipes them and turning the toggle off deletes them.
Contract: `Prefs.omniboxHistoryEnabled` (key `OMNIBOX_HISTORY_ENABLED`, main file, exported) and `Prefs.omniboxHistory` in the separate file `com.parem.launcher.omnibox_history`, which export never reads and backup/extraction rules exclude; `helper/OmniboxHistory` encodes `Entry.App(key)` / `Entry.Query(text)` one per line, and `push` dedupes and caps at `MAX_ENTRIES = 5`.
Not verified: on a device that the history never appears in the export file (the file split is the guarantee; no instrumented test covers it).
Easy to get wrong: the enabled flag exports but the data does not, so an import can turn history on with an empty list — that is correct; setting `omniboxHistoryEnabled = false` clears the data as a side effect.
