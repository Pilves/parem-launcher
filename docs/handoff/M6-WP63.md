Disposable CI emulator test and fixture scripts suppress system error dialogs and check Parem crash/ANR events.
Contract: the wrapper checks an explicit target package and colon subprocesses, keeps original test failures, and fails if event collection is unavailable.
Not verified: injected crashes or ANRs on an emulator, physical devices, or workflows that do not use this wrapper.
Easy to get wrong: clear only the events buffer before the workload; do not clear it between flavors, or ignore the retained incident logs.
Performance comparison runs reference and candidate under the same package, so an incident there needs attribution before blaming either build.
