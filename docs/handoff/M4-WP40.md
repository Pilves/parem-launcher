Focus whitelist, weekly review, usage cache, currency parsing, legacy hidden-app migration and device-only backup state handle their audited edge cases (A27, A32, A34, A49, A50, A51), each pure fix with a JVM test.
Contract: `AppListRebuilder.hiddenKey(pkg, userString)` / `upgradeHiddenApps(set, personalUser)` own the `pkg|user` format; `FocusModeManager.mergeWhitelist(selected, current, offered)`; `WeeklyReview.compare(thisWeek, lastWeek, todayFraction = 1.0)` divides this week by 6 + fraction; `UsageStatsHelper.isCacheStale(now, cachedAt, today, cachedDay)`; `CurrencyConverter.parseAmount` reads `d{1,3},ddd` as thousands; `Prefs.deviceOnlyKeys` (lock-service, focus-session, grayscale moment keys) feeds exportExcludeKeys and `ParemBackupAgent.onRestoreFinished` clears them.
Not verified: a real cloud restore or device transfer calling onRestoreFinished (manifest now declares backupAgent + fullBackupOnly); the focus picker and screen-time sheet on a device; "1.000" with a dot is still read as a decimal.
Easy to get wrong: PrefsRegistrationTest parses `exportExcludeKeys = setOf(...) + deviceOnlyKeys` by regex, so a second `+ set` or a nested setOf breaks it; `mergeWhitelist` puts ticked apps first so the cap of 5 cuts kept entries, not fresh choices.
