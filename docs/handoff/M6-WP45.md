Picker rows retain their checkbox accessibility semantics through filtering and RecyclerView rebinding.
Contract: row node initialization sets checkable and checked state even when RecyclerView bypasses an item delegate; real changes still announce, and binding remains silent.
Not verified: spoken TalkBack, phone and tablet filter interaction or physical e-ink behavior.
Easy to get wrong: RecyclerView suppresses original item delegates while adapter updates are pending.
