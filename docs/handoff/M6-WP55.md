Grayscale recovery and app-limit checks explain missing access or unavailable usage without silently treating it as zero.
Contract: pending restoration follows the current grayscale policy; recovery never turns on manual grayscale, and unknown usage cannot trigger after-limit grayscale.
Not verified: physical-device/OEM color correction and exact restoration; async usage access may change after the final check.
Easy to get wrong: a successful empty event query differs from a failed query, and a pause still applies when the user opens anyway.
