Unavailable widgets retain their ID, order and height as removable, replaceable placeholders until they recover or the user removes them.
Contract: null or failed widget info is unknown; no automatic rebind assumes a profile, and pending swaps target the original widget ID rather than an index.
Not verified: real uninstall/reinstall, work/private profile transitions, safe mode and physical-device behavior.
Easy to get wrong: placeholders count toward the six-widget cap; a provider change or home return must reconcile without resurrecting an explicitly removed ID.
