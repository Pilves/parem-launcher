Unavailable widgets retain their ID, order and height as removable, replaceable placeholders until they recover or the user removes them.
Contract: null or failed widget info is unknown; even confirmed removals retain placeholders; forced refresh preserves unchanged placeholders and pending swaps target their original widget ID.
Not verified: real uninstall/reinstall pending fixture CI, offline uninstall, work/private profile transitions, safe mode and physical-device behavior.
Easy to get wrong: placeholders count toward the cap; pending operations block further widget operations and must never resurrect a removed ID.
