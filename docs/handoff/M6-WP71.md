Downloaded wallpapers decode with the largest power-of-two sample that still covers the screen crop, and the full-size source is freed before the two encodes.
The two fallback wallpapers (used whenever a day's `.dark` or `.light` entry is blank) request `?w=2000&q=99`, the size every daily entry already uses; the originals decoded to 60-81 MB.
Contract: home and lock keep separate `setBitmap` calls (a combined call would make the lock screen share the home wallpaper); a failed download, decode or apply returns false so `WallpaperWorker` does not record the URL.
`dismissOnDestroy` releases its lifecycle observer when the dialog window detaches; call it after `show()`, because before that there is no window and the dialog stays reachable until the owner dies.
The grey-on-focus end job is re-enqueued only when its elapsed-clock fire time changes; an in-memory memo is cleared by `cancelFocusEnd` and when the worker starts, so any new cancel path must clear it too.
Not verified: device memory, the lock screen after a fallback set, or the focus-end timing on hardware; a download cut off partway now fails and retries instead of setting a partial image.
