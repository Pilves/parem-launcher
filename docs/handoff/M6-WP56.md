Cancelling widget configuration releases the new unsaved ID and leaves any existing widget in place.
Contract: the existing Boolean result format and pending-operation restore remain compatible; configure Cancel never replaces the existing widget.
Not verified: work-profile configure results, physical devices and ambiguous pre-#59 overlaps or arbitrary stale callbacks.
Easy to get wrong: cancellation can return null data and must not query the provider or delete an already-saved widget ID.
