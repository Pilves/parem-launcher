Cancelling widget configuration releases the new unsaved ID and leaves any existing widget in place.
Contract: pending results retain their accepted operation and source; known ID or stage mismatches cannot consume another operation.
Not verified: work-profile configure results, physical devices and arbitrary external stale callbacks without an identifying ID.
Easy to get wrong: cancellation can return null data and must not query the provider or delete an already-saved widget ID.
