The widget picker groups by app and profile, filters by app or widget name, and shows dimensions on every widget row; headings and rows are text-only.
Contract: a bounded scrollable title/search region keeps search reachable in short windows above one widget ListView; provider clicks preserve the original bind path and IDs.
Profile: 120 synthetic providers; eager static prototype added about 35–46 MiB PSS versus 2–12 MiB for text rows on separate runners; 0/120 generated previews were retrievable without a bind grant.
Deferred: bounded, lazily loaded previews; the synthetic shared shapes and separate runners do not show that all previews fail or establish production-device performance.
Localization: no_widgets_found and widget_picker_result_count fall back to English in ar, de, es-rES, es-rUS, et, fr, he, hr, hu, in, it, ja, pl, pt-rBR, ru-rRU, sv, tr, uk and zh; translate in a reviewed follow-up.
Not verified: physical devices, TalkBack, e-ink, work profiles, real keyboard-free hardware and diverse provider icon assets; current CI evidence and limits are in the PR.
Easy to get wrong: never bind widgets to obtain a preview, assume profile identity from package alone, or put fixed padding inside a tiny list viewport.
