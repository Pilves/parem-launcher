Home skips repeated first-run tip updates when their text, visibility and the default-home prompt are unchanged.
Contract: tip and default-home prompt changes still update reserved space; the cached prompt state resets with the view.
Not verified: real-device timing, visible-tip timing and retained-view geometry changes without a new update remain unmeasured.
Easy to get wrong: default-home visibility must be compared even while tips are hidden.
