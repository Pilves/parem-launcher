# v6.0.2 export fixture

`v6.0.2-settings.json` is the unmodified file produced by the published
[ParemLauncher-v6.0.2.apk](https://github.com/Pilves/parem-launcher/releases/tag/v6.0.2)
(package `com.parem.launcher`, versionCode 107); it is not synthesized test data.
The APK SHA-256 is `0681798e77ea60664c0c76a3952a004268ab1b85032fd801990d517f63e7b80b`;
the fixture SHA-256 is `15eac9639d5150a5d2be3186429f346218a3cf33917c49f9862d5b02fe7a21bd`.

[CI run 43562390600](https://github.com/Pilves/parem-launcher/actions/runs/43562390600)
on capture commit `e221175d419bf923bd4aefac1f252546a79ce602` installed the released APK
on a fresh API 34 Pixel 6 emulator, completed onboarding, searched `2+2`, returned
home, opened Settings, enabled Daily wallpaper, and tapped Export settings. The
separate UI driver pulled the resulting Downloads file. Its output and APK identity
are preserved in the run's `released-export-capture` artifact (subject to retention).
The file includes that disposable emulator's timestamp, clock package and wallpaper URL.
A v5.5.1 export was not available in the existing upgrade fixture.

The capture workflow uses the same driver and pinned APK. JVM parsing uses the
`org.json` test library; the platform's Android JSON implementation and import UI
are not exercised by this JVM fixture check.
