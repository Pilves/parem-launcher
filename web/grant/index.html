Allow grayscale for Parem

  1. On the phone, turn on Developer options (Settings > About phone > tap Build number 7 times), then USB debugging.
  2. Plug the phone into this computer.
  3. Click Grant, pick the phone, and tap Allow on the phone if it asks about USB debugging.

This page runs only in your browser. It sends nothing anywhere and runs one command: granting Parem permission to change color settings.

Needs Chrome or Edge on a computer. Prefer a terminal? Run adb shell pm grant com.parem.launcher android.permission.WRITE_SECURE_SETTINGS

To get color back at any time, without Parem: Settings > Accessibility > Color correction.
